# 📅 EventEase  

EventEase is a **modern event management platform** that helps users create, manage, and attend events effortlessly. It supports features like event creation, ticketing, registration, payments, and admin management, making it an all-in-one solution for organizers and attendees.  

---

## ✨ Features  

### 👥 User Features
- 🔑 **Authentication**: Secure login & registration with JWT  
- 📝 **Event Creation**: Add event details including type, description, location, date & time  
- 🎟️ **Ticketing System**: Multiple ticket types, pricing & discounts  
- 🛒 **Event Registration**: Book tickets with integrated payment gateway (Razorpay)  
- 📅 **Event Dashboard**: View upcoming, current, and past events  
- ✅ **Verification System**: Organizers must verify before creating events  

### 🛠️ Admin Features
- 📊 **Admin Dashboard**: Manage users & events  
- ✅ **Event Approval Workflow**: Review & approve/reject submitted events  
- 📈 **Analytics**: Track event statistics and user engagement  
- 🔎 **Filters & Tabs**: Filter events by type (Conferences, Concerts, etc.) and status  

---

## 🏗️ Tech Stack  

**Frontend**  
- ⚛️ React.js + TailwindCSS  
- 📦 shadcn/ui for UI components  

**Backend**  
- 🚀 Node.js + Express.js  
- 🗄️ MongoDB with Mongoose ORM  
- 🔐 JWT for authentication  
- 💳 Razorpay API integration for payments
